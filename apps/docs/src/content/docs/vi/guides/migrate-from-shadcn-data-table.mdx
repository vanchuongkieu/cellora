Tài liệu **Data Table** của shadcn/ui chỉ cách ráp bảng từ TanStack Table và các primitive `<Table>`. Điểm khởi đầu tốt, nhưng là rất nhiều code phải bảo trì. Cellora giữ nguyên giao diện và thay phần ráp bằng props. Trang này đối chiếu từng phần.

## Cột

TanStack:

```tsx
const columns: ColumnDef<Payment>[] = [
  { accessorKey: "status", header: "Status" },
  {
    accessorKey: "email",
    header: ({ column }) => (
      <Button variant="ghost" onClick={() => column.toggleSorting()}>
        Email
      </Button>
    ),
  },
  { accessorKey: "amount", header: () => <div className="text-right">Amount</div>, cell: ({ row }) => <div className="text-right">{format(row.getValue("amount"))}</div> },
]
```

Cellora:

```tsx
const columns: DataGridColumnInput<Payment>[] = [
  { id: "status", header: "Status", accessor: (row) => row.status },
  { id: "email", header: "Email", accessor: (row) => row.email, sortable: true },
  { id: "amount", header: "Amount", accessor: (row) => row.amount, align: "right", sortable: true, cell: (row) => format(row.amount) },
]
```

| TanStack                                                          | Cellora                                                                                |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `accessorKey: "email"`                                            | `id: "email", accessor: (row) => row.email` (hoặc `<DataGrid.Column field="email" />`) |
| `header: ({ column }) => <Button onClick={column.toggleSorting}>` | `sortable: true` (cả ô tiêu đề là vùng bấm, có sẵn icon)                               |
| `cell: ({ row }) => …`                                            | `cell: (row, { grid, index }) => …`                                                    |
| `enableSorting: false`                                            | không đặt `sortable`                                                                   |
| `enableHiding: false`                                             | `hideable: false`                                                                      |
| `size`                                                            | `width`                                                                                |
| mẹo `meta.align`                                                  | `align: "right"`                                                                       |

## Component bảng

TanStack + shadcn/ui: `useReactTable` với `getCoreRowModel`, `getSortedRowModel`, `getFilteredRowModel`, `getPaginationRowModel`, rồi 60 dòng markup `<Table>`, toolbar có `<Input>` nối với `table.getColumn("email")?.setFilterValue`, footer phân trang với `table.previousPage()` …

Cellora:

```tsx
<DataGrid rows={data} columns={columns} getRowId={(row) => row.id} enableSorting enableSearch enableRowSelection />
```

| Tính năng TanStack                                     | Prop Cellora                                                 |
| ------------------------------------------------------ | ------------------------------------------------------------ |
| `getSortedRowModel()` + nút ở tiêu đề                  | `enableSorting`                                              |
| Ô lọc một cột                                          | `enableSearch` (mọi cột) hoặc bộ lọc theo cột trong menu cột |
| `getPaginationRowModel()` + nút footer                 | bật sẵn; `pageSize`, `pageSizeOptions`                       |
| Cột checkbox chọn dòng                                 | `enableRowSelection`, `onSelectionChange`                    |
| Dropdown ẩn/hiện cột                                   | menu cột → Manage columns                                    |
| `manualPagination`, `manualSorting`, `manualFiltering` | cùng tên, thêm `rowCount` và `onStateChange`                 |
| `rowCount`                                             | `rowCount`                                                   |
| Toolbar tự làm                                         | slot `<DataGrid.Toolbar>` hoặc `slots.toolbar`               |
| Dòng "No results."                                     | `emptyMessage` hoặc slot `empty`                             |

## State bạn từng tự quản

`useState` cho sorting, column filters, visibility và row selection không cần nữa. Đọc từ grid API trong slot (`grid.state`, `grid.selection`) hoặc kiểm soát bằng `sort` / `filter` / `columnFilters` / `pageIndex` / `selectedRowIds` và các callback `on…Change` khi cần đưa lên URL.

## Được thêm gì

Cuộn ảo một triệu dòng, ghim cột, nhóm cột, nhóm dòng có tổng, sửa ô, tìm kiếm không dấu, label để đa ngôn ngữ, core không phụ thuộc framework, mà không thêm thư viện.

## Kiểm tra sau khi chuyển

- `getRowId` phải trả id ổn định nếu dòng có thể đổi thứ tự hoặc tải lại (chọn dòng và sửa ô dựa vào nó).
- `cell` tuỳ biến nhận thẳng dòng, không phải object `row` của TanStack.
- Style ghi đè chuyển từ `className` trên `<TableCell>` sang `classNames={{ cell: "…" }}` hoặc `cell` theo cột.
