```tsx
import { DataGrid } from "@cellora/react"
```

`TRow` là kiểu của một dòng; được suy ra từ `rows`.

## Dữ liệu

| Prop       | Kiểu                                   | Mặc định    | Mô tả                                                                                                                 |
| ---------- | -------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------- |
| `rows`     | `readonly TRow[]`                      | bắt buộc    | Dữ liệu. Không bao giờ bị sửa; truyền mảng mới để thay đổi.                                                           |
| `columns`  | `readonly DataGridColumnInput<TRow>[]` |             | Các cột ([tham chiếu](/vi/api/column/)). Không bắt buộc khi dùng cột JSX.                                             |
| `children` | `ReactNode`                            |             | `<DataGrid.Column>` và các phần slot ([cột JSX](/vi/getting-started/jsx-columns/), [slot](/vi/customization/slots/)). |
| `getRowId` | `(row, index) => string`               | chỉ số dòng | Id ổn định cho mỗi dòng: chọn dòng và sửa ô dựa vào nó.                                                               |

## Giao diện

| Prop                | Kiểu                                           | Mặc định        | Mô tả                                                                  |
| ------------------- | ---------------------------------------------- | --------------- | ---------------------------------------------------------------------- |
| `className`         | `string`                                       |                 | Class cho khung ngoài.                                                 |
| `classNames`        | `Partial<Record<DataGridPart, string>>`        |                 | Class thêm theo từng phần ([giao diện](/vi/getting-started/styling/)). |
| `styles`            | `Partial<Record<DataGridPart, CSSProperties>>` |                 | Style inline theo từng phần.                                           |
| `bordered`          | `boolean`                                      | `false`         | Có đường kẻ giữa các cột.                                              |
| `rowClassName`      | `(row, index) => string \| undefined`          |                 | Class thêm cho từng dòng.                                              |
| `slots`             | `DataGridSlots<TRow>`                          |                 | Thay các phần ([danh sách slot](/vi/api/slots/)).                      |
| `components`        | `DataGridSlotComponents<TRow>`                 |                 | Các slot dạng component.                                               |
| `labels`            | `Partial<DataGridLabels>`                      | tiếng Anh       | Mọi câu chữ ([nhãn](/vi/customization/labels/)).                       |
| `searchPlaceholder` | `string`                                       | `"Search..."`   | Chữ gợi ý ô tìm kiếm.                                                  |
| `emptyMessage`      | `string`                                       | `"No results."` | Chữ khi không có gì khớp.                                              |

## Sắp xếp, tìm kiếm, lọc

| Prop            | Kiểu                     | Mặc định | Mô tả                                                                              |
| --------------- | ------------------------ | -------- | ---------------------------------------------------------------------------------- |
| `enableSorting` | `boolean`                | `false`  | Sắp xếp theo tiêu đề; cột bật bằng `sortable` ([sắp xếp](/vi/features/sorting/)).  |
| `enableSearch`  | `boolean`                | `false`  | Ô tìm kiếm ([tìm kiếm](/vi/features/search/)).                                     |
| `ignoreAccents` | `boolean`                | `true`   | Tìm kiếm và lọc không phân biệt dấu (`nguyen` tìm được `Nguyễn`).                  |
| `searchFilter`  | `(row, term) => boolean` | mặc định | Hàm tìm kiếm riêng, thay cho "có cột chứa chữ" ([tìm kiếm](/vi/features/search/)). |

Bộ lọc theo cột nằm trong menu cột ([lọc theo cột](/vi/features/column-filters/)). Cách khớp và thứ tự theo từng cột là tuỳ chọn của cột: `searchValue`, `searchable`, `sortValue`, `compare`, `filterValue`, `filterMatch` ([cột](/vi/api/column/#quy-tắc-tìm-kiếm-sắp-xếp-và-lọc)).

## State (điều khiển hoặc ban đầu)

Sắp xếp, tìm kiếm, bộ lọc và trang do grid giữ. Mỗi thứ có thể có giá trị ban đầu hoặc được kiểm soát; `onStateChange` báo mọi thay đổi ([dữ liệu phía server](/vi/features/server-side/)).

| Prop                   | Kiểu                              | Mặc định | Mô tả                                          |
| ---------------------- | --------------------------------- | -------- | ---------------------------------------------- |
| `sort`                 | `{ columnId, direction } \| null` |          | Sắp xếp có kiểm soát.                          |
| `defaultSort`          | `{ columnId, direction } \| null` | `null`   | Sắp xếp ban đầu.                               |
| `filter`               | `string`                          |          | Chữ tìm kiếm có kiểm soát.                     |
| `defaultFilter`        | `string`                          | `""`     | Chữ tìm kiếm ban đầu.                          |
| `columnFilters`        | `Record<string, string>`          |          | Bộ lọc cột có kiểm soát (theo id cột).         |
| `defaultColumnFilters` | `Record<string, string>`          | `{}`     | Bộ lọc cột ban đầu.                            |
| `pageIndex`            | `number`                          |          | Trang có kiểm soát (đếm từ 0).                 |
| `defaultPageIndex`     | `number`                          | `0`      | Trang ban đầu.                                 |
| `onStateChange`        | `(state: DataGridState) => void`  |          | Toàn bộ state sau mỗi thao tác của người dùng. |

## Xử lý phía server

| Prop               | Kiểu      | Mặc định      | Mô tả                                                                                    |
| ------------------ | --------- | ------------- | ---------------------------------------------------------------------------------------- |
| `manualSorting`    | `boolean` | `false`       | `rows` đã sắp xếp sẵn: hiển thị nguyên trạng ([phía server](/vi/features/server-side/)). |
| `manualFiltering`  | `boolean` | `false`       | `rows` đã khớp tìm kiếm và bộ lọc.                                                       |
| `manualPagination` | `boolean` | `false`       | `rows` là một trang; không bao giờ bị cắt.                                               |
| `rowCount`         | `number`  | `rows.length` | Số dòng khớp trên mọi trang (với `manualPagination`).                                    |

## Phần tĩnh
