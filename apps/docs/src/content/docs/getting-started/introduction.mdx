**Cellora** is a data grid for React. It is built from [shadcn/ui](https://ui.shadcn.com) components and Tailwind CSS, so it looks like the rest of your app from the first render, and it stays fast with a million rows.

## What you get

- **Data features**: sorting, search, per-column filters, pagination, row grouping with totals, inline editing, row selection that survives paging.
- **Layout features**: fixed column widths, drag / double-click / keyboard resizing, pinned columns on either side, sticky header, column groups, fill-the-screen height.
- **Scale**: virtual scrolling for rows _and_ columns. 1,000,000 rows × 100 columns scroll at 60 fps.
- **Customization**: every part of the chrome is a slot (30+), every string is a label (i18n), every part takes extra classes and styles.
- **Your data stays yours**: the grid never copies or mutates your rows. Edits are reported to you; you decide what to save.

## Two packages

| Package          | What it is                                                                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@cellora/react` | The `DataGrid` component and its hooks. This is what you install.                                                                                  |
| `@cellora/core`  | Framework-free logic: sorting, filtering, grouping, windowing math. Installed with `@cellora/react`; usable on its own (a Vue binding is planned). |

## Browser support

Current Chrome, Edge, Firefox and Safari (desktop and mobile). Server rendering works (Next.js App Router, Astro, Remix): the package is marked `"use client"`.
