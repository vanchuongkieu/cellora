## Three ways to fill a slot

### 1. `slots`: functions

```tsx
<DataGrid slots={{ sortIcon: (direction) => (direction === "asc" ? "▲" : direction === "desc" ? "▼" : "↕") }} />
```

### 2. `components`: React components

Hooks work inside. Slots called with the grid (`toolbar`, `search`, `empty`, `groupPanel`, `loadingOverlay`, `footer`) receive `{ grid }`; `sortIcon` receives `{ direction }`; the others receive their context object as props.

```tsx
function Toolbar({ grid }: { grid: DataGridApi<Employee> }) {
  const [open, setOpen] = useState(false)
  return <div>{grid.result.total} rows</div>
}

;<DataGrid components={{ toolbar: Toolbar }} />
```

### 3. JSX children

```tsx
<DataGrid rows={rows} columns={columns}>
  <DataGrid.Empty>Nothing here yet.</DataGrid.Empty>
  <DataGrid.Toolbar>{(grid) => <MyToolbar grid={grid} />}</DataGrid.Toolbar>
  <DataGridSlot name="range">{({ from, to, total }) => `${from}–${to} / ${total}`}</DataGridSlot>
</DataGrid>
```

Each slot has a part named after it: `DataGrid.Toolbar`, `DataGrid.Empty`, `DataGrid.SortIcon`, … Children can be content, a render function, or `component={MyComponent}`.

## Which wins

**JSX children → `components` → `slots`.** You can mix them; the stronger one replaces the weaker one for the same slot.

## Rows and group rows

`row`, `groupRow` and `footerRow` get the default `cells` so you can wrap them:

- In table mode return a `<tr>`.
- When [virtualized](/features/virtual-scroll/) the row element exists already: return what goes inside it (e.g. `<div className="contents">{cells}</div>`).
